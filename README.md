## Présentation

Permet aux VIP de modifier les pancartes déjà posées sur leur île.

Utilisé sur : **Opale**.

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shsignedit.use` | Permet d'éditer les pancartes sur son propre île. | `op` |
| `shsignedit.bypass` | Permet de contourner toutes les restrictions d'édition des pancartes. | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`). Cliquez sur un fichier pour l'ouvrir :

<pre>
plugins/SHSignEdit/
└── <a href="src/main/resources/config.yml">config.yml</a>
</pre>

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
